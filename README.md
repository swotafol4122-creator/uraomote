# ウラオモテ

すべての札に**表**と**裏**があるカードゲーム。165種・330の顔。
ホーム画面に追加すると、アドレス欄のないアプリとして起動し、電波がなくても遊べます。

---

## 1. GitHubに置く（5つのファイル）

リポジトリの**直下**に、この5つを置きます。フォルダは作りません。

```
index.html          ← ゲーム本体
manifest.json       ← アプリの名前・色・アイコンの設定
sw.js               ← 電波がなくても動かすための係
icon-512.png        ← ホーム画面のアイコン
icon-maskable.png   ← Android用（丸や角丸に切り抜かれる版）
```

`README.md` は説明用なので、上げても上げなくてもかまいません。

### 手順

1. **github.com** でアカウントを作る（無料）
2. 右上の **＋ → New repository** → 名前を `uraomote` → **Public** → **Create repository**
3. **Add file → Upload files** で、上の5つを**まとめて**選ぶ
4. 下までスクロールして **Commit changes** を押す（ここを押さないと保存されません）
5. ファイル一覧に5つ並んでいることを確認する
6. **Settings → Pages** で、**Source** を `Deploy from a branch`、
   **Branch** を `main` / `/ (root)` にして **Save**
7. 1〜2分待つと、Settings → Pages の上部に出るURLで開けます

```
https://＜ユーザー名＞.github.io/uraomote/
```

### 白い画面に「ウラオモテ」とだけ出るとき

それは `README.md` が表示されています。`index.html` がリポジトリ直下に無い証拠です。
アドレスの末尾に `/index.html` を足して開き、404が出るなら上げ直してください。
正しければ**黒に近い背景に金色の文字**が出ます。

### 更新したいとき

同じ手順で `index.html` を上げ直すだけです。次に開いたときに自動で新しくなります。

## 2. ホーム画面に追加する

公開したURLをスマホで開いて、

- **Android / Chrome** … メニュー（⋮）→「アプリをインストール」または「ホーム画面に追加」
  （画面内に「ホーム画面に追加する」ボタンが出ることもあります）
- **iPhone / Safari** … 共有ボタン →「ホーム画面に追加」

追加すると、アイコンから直接起動し、アドレス欄も出ません。
一度開いておけば、**機内モードでも遊べます**。

---

## 3. 友達と対戦する

タイトル画面か「盤上十二門」の画面から**友達と対戦する**を選びます。

### 同じ端末で交互に指す
1台を回して遊びます。手番が変わるたび画面が伏せられ、
「◯◯として始める」を押すまで相手の手札は見えません。**確実に動きます。**
後手が使う組札は、自分の組札（最大6つ）から選べます。

### 二台をつないで指す（合言葉）
二台が**直接**つながります。途中にサーバーはありません。

1. 片方が「**部屋を作る**」→ **招きのリンク**をコピーしてLINEなどで送る
2. 相手がリンクをタップ → 自動で読み込まれ、**返しの合言葉**が出る
3. 相手がその合言葉をコピーして送り返す
4. 部屋を作った側が貼り付けて「**つなぐ**」→ 対戦開始

同じWi-Fiならほぼ確実につながります。携帯回線どうしだと回線の種類によって
つながらないことがあるので、そのときは「同じ端末で交互に」を使ってください。

---

## 4. 遊びかた（要点だけ）

- 相手の**命**を0にすれば勝ち。命は20から。
- **気は自然に増えません。** 自分の手番に手札を1枚「気脈に伏せる」と、
  使える気が1増えます（上限10）。毎ターン「燃料にするか、戦力にするか」を選び続けます。
- 場は左・中・右の**3列**。ユニットは**正面の敵だけ**を攻撃し、正面が空いていれば
  相手の命を直接殴れます。1ターンに1体だけ空き列へ**陣替え**できます。
- 札は出すときに**表か裏かを選びます**。名前も気の値も能力も別物です。
- 反転しても**受けた傷はそのまま引き継ぎます**。自分から反転できるのは**二面**を持つ札だけ。

詳しい説明はゲーム内の「掟」に全部書いてあります。

---

## 5. 保存・音・戻るボタン

- 進行状況（札・魂片・組札・突破した門・音の設定）はその端末に自動保存されます。
  サーバーには何も送られません。別端末への引き継ぎはできません。
- BGMも効果音も**音源ファイルを持たず、その場で合成**しています（Web Audio）。
  画面内の **♪** から曲と効果音を別々に切り替えられます。
  ブラウザの決まりで、最初に画面をどこか触るまでは鳴りません。
- Androidの戻るボタンは、アプリを閉じずに画面内を1段ずつ戻ります。
  対戦中に押すと確認が出ます。

## 6. 動作環境

- Android の Chrome / iOS 16.4 以降の Safari / 最近の Edge・Firefox
- 二台接続には WebRTC が使える環境が必要です
